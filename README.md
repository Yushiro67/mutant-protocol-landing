# Mutant Protocol Nexus

Build a cinematic, immersive, and interactive event landing page for "MUTANT PROTOCOL: The Bennett Initiative", hosted by the GeeksForGeeks Student Chapter, Bennett University.
The design direction blends dark, high-tech X-Men aesthetics (Cerebro, Danger Room, Xavier Institute blueprints, neon mutant energy) with an "Avengers Multiverse Assembly" showcase featuring high-res imagery and dossiers of Earth’s Mightiest Heroes.
### 1. Visual Direction & Style
- Palette: Void black (#05070B), Cerebro cyan/electric blue (#00F0FF), Danger Room amber/gold (#FFB800), and Mutant Crimson (#E62429).
- Typography: Bold condensed display headlines (like Bebas Neue, Clash Display, or Oswald) paired with clean sci-fi monospace/sans body text (Inter or JetBrains Mono).
- Effects: Subtle grid overlays, glassmorphic HUD cards with glowing neon borders, scanlines, particle dust/energy aura in backgrounds, and smooth scroll transitions.
- High-fidelity imagery: Use Unsplash Marvel/sci-fi cosplay and action visuals, Marvel hero portrait cards with stylized lighting (Iron Man, Captain America, Thor, Scarlet Witch, Wolverine, Magneto).
### 2. Website Architecture & Sections
1. Navbar / Tactical HUD:
   - GFG Bennett University Chapter x Marvel logo lockup.
   - Navigation links: [Intel / Overview], [Speakers & Mentors], [Timeline], [Avengers Dossier], [Prizes], [FAQ].
   - Right side: Audio toggle button ("Ambient SFX / Cerebro Hum") and a glowing "Initiate Protocol" (Register) CTA button.
2. Hero Section ("The Awakening"):
   - Bold, cinematic headline: "EVOLVE OR FALL BEHIND."
   - Subtitle: "GeeksForGeeks Bennett University summons coders, designers, and tech mutants for a 36-hour hackathon & tech summit."
   - Dynamic live countdown timer to event launch date.
   - Dual CTAs: Primary "Register Your Squad" (magnetic glow button) and Secondary "Watch Teaser / Read Brief".
   - Subtle holographic background effect with interactive cursor tracking or floating energy particles.
3. Mission Brief / Event Highlights (Interactive Bento Grid):
   - 4-card high-tech grid showcasing:
     * 36 Hours of Non-stop Creation
     * ₹1,00,000+ Prize Pool + Stark Industries Tier Swag
     * Mentorship from Industry Titans (FAANG / Marvel-level experts)
     * Exclusive Networking & Danger Room Coding Battles
4. "Avengers Assembly" Interactive Hero Dossier:
   - An interactive carousel or 3D card deck featuring Avengers and X-Men characters representing hackathon tracks/domains:
     * Iron Man / Tony Stark -> AI & Robotics Track
     * Wolverine / Logan -> Cybersecurity & Defense Systems
     * Professor X / Jean Grey -> Neural Networks & Brain-Computer Interfaces
     * Thor / Storm -> Cloud Architecture & High-Performance Computing
     * Scarlet Witch / Doctor Strange -> Web3, AR/VR & Spatial Computing
   - Each card flips or expands into a modal with track details, recommended tech stacks, and track-specific prizes.
5. Event Schedule / Danger Room Timeline:
   - Interactive tabbed schedule (Day 1: Genesis, Day 2: The Crucible, Day 3: Endgame).
   - Timeline nodes light up with glowing pulses on hover.
6. Squad Registration & Terminal Input (Interactive Form):
   - Terminal-themed registration card ("Cerebro Access Terminal").
   - Fields: Mutant Alias / Name, College Email, University Roll No, Selected Track (Dropdown), Squad / Team Name, GitHub / Portfolio URL.
   - Interactive badge preview: As the user types, a live holographic "Agent ID Card" renders their name, role, and avatar.
   - Real-time form validation with success modal ("Clearance Granted: Welcome to the Initiative").
7. Frequently Asked Questions (FAQ Accordion):
   - Clean, expandable accordion answering eligibility, team size (1-4 mutants), venue, accommodation, and hardware requirements.
8. Tactical Footer:
   - GFG Student Chapter Bennett University branding and social links (Instagram, LinkedIn, GitHub, Discord).
   - Easter egg button: "Activate Cerebro" that triggers a neon glitch or particle wave animation across the screen.
   - Copyright & disclaimer: "Fan-made event experience by GFG Bennett Student Chapter."
### 3. Polish & Interactions
- Smooth micro-interactions on every button, card hover, and badge.
- Fully mobile-responsive layout with seamless drawer navigation on small screens.
- Fallback placeholder images from Unsplash using superhero / cyberpunk / futuristic sci-fi queries.
